# «Кітаптан – жақсы іске» — EdTech цифрлық платформасы

> **Жобаның тақырыбы:** «Кітаптан – жақсы іске: цифрлық платформа арқылы бастауыш сынып оқушысының оқырмандық және тәрбиелік белсенділігін арттыру»

## 🌟 Басты формула
```
📚 ОҚЫ → 💡 ТҮСІН → 🎮 ОЙНА → ❤️ ЖАҚСЫ ІС ЖАСА → 👨‍👩‍👧 ОТБАСЫҢМЕН БӨЛІС
```

**Ұран:** «Әр оқылған кітап — бір жақсы әрекетке бастайды!»

---

## 🚀 Технологиялық стек

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript
- **Стиль және UI:** Tailwind CSS, shadcn/ui тәсілі, Lucide Icons, Canvas Confetti
- **Backend & Database:** Supabase, PostgreSQL, Supabase Auth & Storage
- **Тіл:** Толықтай мемлекеттік тілде (қазақша)

---

## 🎨 Дизайн жүйесі (Kid-Friendly Premium EdTech)

- **Түстер жүйесі:**
  - ⚪ Ақ және жұмсақ бұлтты фон (`#F8FAFC`, `#FFFDF7`)
  - 💧 Ашық көк (`#38BDF8`, `#0284C7`) — оқу және таным
  - ☀️ Жұмсақ сары (`#FACC15`, `#F59E0B`) — ойын, энергия және тиындар
  - 🌿 Балғын жасыл (`#22C55E`, `#16A34A`) — жақсы істер мен өсім
  - 💜 Күлгін акцент (`#A855F7`, `#7E22CE`) — шығармашылық және викториналар
  - 💖 Жылы корал/қызғылт (`#FB7185`, `#F43F5E`) — қайырымдылық және жүрек
- **Элементтер:** 3D көлемді батырмалар, `rounded-3xl` дөңгеленген карточкалар, жұмсақ пастельді көлеңкелер, анимациялар.

```
│   │       ├── layout.tsx         # Кабинет Layout (Sidebar + Header + Mobile Nav)

│   │   └── ui/
│   │       ├── button.tsx         # 3D басылатын көлемді батырмалар
│   │       ├── card.tsx           # Дөңгеленген карточкалар
│   │       ├── badge.tsx          # Сынып, ұпай және мәртебе белгілері
│   │       ├── progress.tsx       # Түрлі-түсті деңгей жолағы
│   │       ├── avatar.tsx         # Оқушы маскоттары мен кейіпкерлері

│   │       └── input.tsx          # Ыңғайлы форма өрістері
│   ├── lib/
│   │   ├── utils.ts               # cn() кластар утилиті
│   │   ├── mock-data.ts           # Кітаптар, жақсы істер, жетістіктер деректері
│   │   └── supabase/
│   │       ├── client.ts          # Браузерге арналған Supabase клиенті
│   │       └── server.ts          # Серверлік Supabase клиенті
│   └── types/
│       └── database.types.ts      # Дерекқордың TypeScript типтері
├── supabase/
│   └── schema.sql                 # PostgreSQL толық кестелері мен RLS саясаттары
```

## ⚡ Жобаны іске қосу

1. **Тәуелділіктерді орнату:**
   ```bash
   npm install
   ```

2. **Әзірлеу режимін қосу (Dev server):**
   ```bash
   npm run dev
   ```
   Браузерден ашыңыз: `http://localhost:3000`

3. **Жобаны жинау (Build):**
   ```bash
   npm run build
   ```
